# Códigos para Práctico — Prof. David Cerdeño (LAPIS 2026)

Repositorio de materiales y códigos para el práctico del Profesor David Cerdeño (*The cosmological origin and direct detection of dark matter*) en la escuela de astrofísica **XII LAPIS 2026**.

## Instrucciones del Práctico y Descripción Completa

- **Descripción completa del proyecto (Google Drive)**: [Ver documento de instrucciones](https://drive.google.com/file/d/1Yolh2rlnA2oWj7c9BB_FPYhOuzrthl4S/view?usp=sharing)
- **Actividades del proyecto**:
  1. Cálculo de tasas de retroceso nuclear y espectros en experimentos de xenón (usando parámetros de referencia de LZ).
  2. Comparación entre un WIMP elástico estándar y materia oscura inelástica.
  3. Ajuste al evento candidato reportado por LZ (`arXiv:2609.02823`, ~248 keV).
